# Assignment alignment and submission checklist

The supplied handout is the source for these requirements. The user's chosen
concept is chemical equation balancing. Its acceptance as an alternative topic
has **not been confirmed**; do not describe it as instructor-approved.

| Handout requirement | ChemMatrix evidence / deliverable |
| --- | --- |
| Choose a real-world system | Conservation of atoms in chemical equations; chemistry is outside the four explicitly listed categories. |
| Identify unknowns and coefficients | Model view maps a, b, c, d to compound coefficients. |
| Derive 3–5 simultaneous equations | Propane example gives three equations: C, H, O. |
| Show AX = B and label matrices | Model view and mathematics guide show A, x, and B=0 with dimensions. |
| Use a permitted matrix method | Exact Gauss–Jordan elimination, with each elementary row operation shown. |
| Substitute into original equations | Verification view gives atom totals and Ax=0; mathematics guide explicitly substitutes propane values. |
| Interpret results | Smallest coefficient ratios describe relative molecules or moles. |
| Develop a visual/computational prototype | Tkinter application with Balancer and Practice tabs. |
| 3–5 minute video | Timed script in presentation-script.md; recording remains to be done. |
| 2–3 page written report | report-draft.md; group details, final formatting, and pagination remain to be done. |
| Include prototype/source | main.py, chemmatrix package, requirements.txt, README, and tests. |

## Before submission

- [ ] Confirm the instructor accepts the chemistry concept.
- [ ] Fill in group members, course/section, instructor, and date in the report.
- [ ] Format and check the report occupies 2–3 pages.
- [ ] Complete the hands-on checks in validation.md on the presentation computer.
- [ ] Rehearse the script, checking that narration matches the displayed output.
- [ ] Record and check the video duration is 3–5 minutes.
- [ ] Include source and documentation; exclude local environments and caches.

Practice mode extends the prototype; it is not evidence of measured learning
improvement. Atom conservation is not evidence of reaction feasibility.
